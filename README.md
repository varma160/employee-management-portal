# 👨‍💼 Employee Management Portal

**🚀 Azure DevOps CI/CD Project**

A modern Employee Management Portal built using HTML, CSS and JavaScript.

---

## 🌟 Project Overview

The Employee Management Portal is a web-based application designed to manage employee information through a simple and user-friendly dashboard.

## ✨ Features

- 📊 Employee Dashboard
- 👥 Employee Management
- ➕ Add Employee
- 🏢 Department Management
- 📈 Reports
- 👤 Employee Profile
- 🔐 Logout

## 🛠️ Technologies Used

- 🌐 HTML
- 🎨 CSS
- ⚡ JavaScript
- ☁️ Azure DevOps
- 🚀 Azure Static Web Apps
- 📦 GitHub

## 🔄 CI/CD Workflow

Developer → GitHub → Azure DevOps → CI/CD Pipeline → Azure Static Web Apps → Live Website 🚀
